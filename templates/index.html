Improved Euler — Heun's Method

A second-order predictor-corrector method for solving ordinary differential equations with improved accuracy over the classical Euler method.

Order 2 Predictor–Corrector Initial Value Problems Runge–Kutta Family
01 — Mathematical Discussion

Theory & Derivation

Heun's Method, also known as the Improved Euler Method, is a second-order Runge–Kutta technique for numerically solving ordinary differential equations (ODEs) of the form:

$$\frac{dy}{dx} = f(x,\, y), \qquad y(x_0) = y_0$$

The classical Euler method uses only a single slope estimate at the beginning of each interval, leading to first-order accuracy \((O(h))\). Heun's method improves this by computing a predictor with Euler, then using the slope at the predicted point to form a corrector — averaging both slopes for a more accurate update. This gives second-order accuracy \((O(h^2))\).

The Algorithm

Given step size $h$ and current point $(x_i,\, y_i)$, each iteration performs two slope evaluations:

$$\text{\textbf{Predictor (Euler step):}}\quad \tilde{y}_{i+1} = y_i + h \cdot f(x_i,\, y_i)$$
$$\text{\textbf{Corrector (average slopes):}}\quad y_{i+1} = y_i + \frac{h}{2}\bigl[f(x_i,\, y_i) + f(x_{i+1},\, \tilde{y}_{i+1})\bigr]$$

Defining the two slope evaluations explicitly:

$$k_1 = f(x_i,\, y_i), \qquad k_2 = f(x_i + h,\; y_i + h\,k_1)$$ $$y_{i+1} = y_i + \frac{h}{2}(k_1 + k_2)$$
  • 1Start with initial conditions $(x_0, y_0)$ and choose step size $h$ and endpoint $x_{\text{end}}$.
  • 2Compute the first slope: $k_1 = f(x_i,\, y_i)$
  • 3Predict: $\tilde{y}_{i+1} = y_i + h \cdot k_1$  (Euler step)
  • 4Compute the second slope: $k_2 = f(x_i + h,\; \tilde{y}_{i+1})$
  • 5Correct: $y_{i+1} = y_i + \dfrac{h}{2}(k_1 + k_2)$  (average slopes)
  • 6Advance: $x_{i+1} = x_i + h$. Repeat from step 2 until $x = x_{\text{end}}$.

Error Analysis & Properties

The local truncation error of Heun's method is $O(h^3)$ per step, giving a global error of $O(h^2)$. This is a significant improvement over the Euler method's $O(h^2)$ local / $O(h)$ global error.

$$\text{Local Truncation Error:}\quad \tau = O(h^3) \qquad\qquad \text{Global Error:}\quad E = O(h^2)$$

02 — Worked Examples

Step-by-Step Solutions

Example 1

Solving $\dfrac{dy}{dx} = x + y$,  $y(0) = 1$,  $h = 0.1$

Given: $f(x, y) = x + y$, $x_0 = 0$, $y_0 = 1$, $h = 0.1$. Find $y$ at $x = 0.2$.

Exact solution: $y = 2e^x - x - 1$

Step 1 — Iteration i = 0  (from $x_0 = 0$ to $x_1 = 0.1$)

$k_1 = f(0,\;1) = 0 + 1 = 1$

$\tilde{y}_1 = 1 + (0.1)(1) = 1.1\quad$ (predictor)

$k_2 = f(0.1,\;1.1) = 0.1 + 1.1 = 1.2$

$y_1 = 1 + \dfrac{0.1}{2}(1 + 1.2) = 1 + 0.05 \times 2.2 = 1 + 0.11 = \mathbf{1.11}$

Step 2 — Iteration i = 1  (from $x_1 = 0.1$ to $x_2 = 0.2$)

$k_1 = f(0.1,\;1.11) = 0.1 + 1.11 = 1.21$

$\tilde{y}_2 = 1.11 + (0.1)(1.21) = 1.11 + 0.121 = 1.231\quad$ (predictor)

$k_2 = f(0.2,\;1.231) = 0.2 + 1.231 = 1.431$

$y_2 = 1.11 + \dfrac{0.1}{2}(1.21 + 1.431) = 1.11 + 0.05 \times 2.641 = 1.11 + 0.13205 = \mathbf{1.24205}$

Example 2

Solving $\dfrac{dy}{dx} = -2xy$,  $y(0) = 1$,  $h = 0.25$

Given: $f(x, y) = -2xy$, $x_0 = 0$, $y_0 = 1$, $h = 0.25$. Find $y$ at $x = 0.75$.

Exact solution: $y = e^{-x^2}$

Step 1 — Iteration i = 0  (from $x_0 = 0$ to $x_1 = 0.25$)

$k_1 = f(0,\;1) = -2(0)(1) = 0$

$\tilde{y}_1 = 1 + (0.25)(0) = 1.0\quad$ (predictor)

$k_2 = f(0.25,\;1.0) = -2(0.25)(1.0) = -0.5$

$y_1 = 1 + \dfrac{0.25}{2}(0 + (-0.5)) = 1 + 0.125 \times (-0.5) = 1 - 0.0625 = \mathbf{0.9375}$

Step 2 — Iteration i = 1  (from $x_1 = 0.25$ to $x_2 = 0.50$)

$k_1 = f(0.25,\;0.9375) = -2(0.25)(0.9375) = -0.46875$

$\tilde{y}_2 = 0.9375 + (0.25)(-0.46875) = 0.9375 - 0.117188 = 0.820313\quad$ (predictor)

$k_2 = f(0.50,\;0.820313) = -2(0.50)(0.820313) = -0.820313$

$y_2 = 0.9375 + \dfrac{0.25}{2}(-0.46875 + (-0.820313)) = 0.9375 + 0.125 \times (-1.289063)$

$y_2 = 0.9375 - 0.161133 = \mathbf{0.776367}$

Step 3 — Iteration i = 2  (from $x_2 = 0.50$ to $x_3 = 0.75$)

$k_1 = f(0.50,\;0.776367) = -2(0.50)(0.776367) = -0.776367$

$\tilde{y}_3 = 0.776367 + (0.25)(-0.776367) = 0.776367 - 0.194092 = 0.582275\quad$ (predictor)

$k_2 = f(0.75,\;0.582275) = -2(0.75)(0.582275) = -0.873413$

$y_3 = 0.776367 + \dfrac{0.25}{2}(-0.776367 + (-0.873413)) = 0.776367 + 0.125 \times (-1.64978)$

$y_3 = 0.776367 - 0.206222 = \mathbf{0.570145}$
